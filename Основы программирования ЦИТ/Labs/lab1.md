## Теоретическая часть

### Структура простейшей программы

```cpp
#include <iostream>
using namespace std;

void main() {
    cout << "Hello World!" << endl;

```

**Общая структура:**
```cpp
директивы_препроцессора

```

### Основные типы данных

| Тип | Размер (байт) | Диапазон |
|-----|---------------|----------|
| `char` | 1 | -128 … 127 |
| `int` | 2 | -32768 … 32767 |
| `short` | 2 | -32768 … 32767 |
| `long` | 4 | -2 147 483 648 … 2 147 483 647 |
| `unsigned char` | 1 | 0 … 255 |
| `unsigned int` | 2 | 0 … 65535 |
| `float` | 4 | ~3.4e-38 … 3.4e+38 |
| `double` | 8 | ~1.7e-308 … 1.7e+308 |

### Ввод/вывод данных

```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;

```

## Примеры программ

### Пример 1. Сумма цифр двузначного числа

```cpp
int main() {
    int a, a1, a2;
    cin >> a;
    a1 = a / 10;
    a2 = a % 10;
    cout << a1 + a2;
    return 0;
}
```

### Пример 2. Вычисление y = cos(|x³ − x²|)

```cpp
#include <iostream>
#include <math.h>
using namespace std;

int main() {
    double x, y;
    cin >> x;
    y = cos(abs(x * x * x - x * x));
    cout << "y = " << y;
    return 0;
}
```

6. Вычислить `y = |x - tg(x)|`.  
7. Вычислить площадь треугольника по стороне и высоте.  
8. Вычислить `y = tg(x) + 5x^3 - 4x^2`.  
9. Вычислить высоту треугольника по двум сторонам и углу между ними.  
10. Вычислить `y = |x - cos(x)|`.  
11. Вычислить `sqrt(x^5 - x^4 + |x^3|)`.  
12. Дано четыре числа. Найти наибольшее (двумя способами: вложенный `if` и парное сравнение).  
13. Дано трёхзначное число. Верно ли, что сумма первой и последней цифр больше квадрата второй?  
14. Дано два числа. Если они разных знаков — найти сумму, иначе — произведение.  
15. Дано два трёхзначных числа. Если сумма цифр первого больше суммы цифр второго, поменять в обоих последнюю и предпоследнюю цифры.  
16. Вычислить и вывести функцию F:

\[
F = \begin{cases} 
-ax - c, & c < 0 \text{ и } x \neq 0 \\
\frac{x-a}{-c}, & c > 0 \text{ и } x = 0 \\
\frac{bx}{c-a}, & \text{в остальных случаях}
\end{cases}
\]

17. Вычислить и вывести функцию F:

\[
F = \begin{cases} 
ax^2 + b, & x < 0 \text{ и } b \neq 0 \\
\frac{x-a}{x-c}, & x > 0 \text{ и } b = 0 \\
\frac{x}{c}, & \text{в остальных случаях}
\end{cases}
\]

18. Вычислить и вывести функцию F:

\[
F = \begin{cases} 
-ax^2, & c < 0 \text{ и } a \neq 0 \\
\frac{a-x}{cx}, & c > 0 \text{ и } a = 0 \\
\frac{1+x}{c}, & \text{в остальных случаях}
\end{cases}
\]

19–22. Вычислить значения выражений с инкрементом/декрементом.  
23. Дано число. Найти количество нечётных цифр.  
24. Дано число. Найти сумму чётных цифр.  
25. Дано число. Найти произведение цифр «2» и «5».  
26. Дано число. Является ли оно числом Фибоначчи?  
27. Дано число. Верно ли, что в его записи нет нулей?  
28. Дано число. Записать его в обратном порядке.  
29. Дано число. Заменить все 0 на 1, а 2 на 5.
