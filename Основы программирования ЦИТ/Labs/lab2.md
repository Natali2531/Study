## Теоретическая часть

### Цикл с предусловием для последовательности с маркером

Когда количество элементов неизвестно, но указан маркер окончания (например, 0), используется цикл `while`:

```cpp
cin >> a;
while (a != 0) {
    // обработка элемента a
    cin >> a;
}
