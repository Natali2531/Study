# Дисциплина «Основы программирования»
## 1 семестр

### 🎯 Цель дисциплины

Формирование у студентов базовых навыков программирования на языке C++, включая:

- Освоение основных синтаксических конструкций языка
- Работа с массивами и матрицами
- Разработка и использование функций
- Работа со структурами данных
- Формирование навыков эффективного взаимодействия с ИИ-ассистентами (промпт-инжиниринг)

---

## 📚 Формы учебной работы

### 1. Лабораторные работы

На очных занятиях студенты выполняют лабораторные работы согласно методическим указаниям.

📄 **Материалы:** [lab.pdf](ссылка)

---

### 2. Индивидуальные задачи

В течение семестра студенты самостоятельно решают индивидуальные задачи согласно своему личному варианту. 

📄 **Варианты заданий:** [варианты.pdf](ссылка)

**Порядок сдачи:**
- Задачи сдаются в течение семестра на лабораторных занятиях
- Форма сдачи: **электронный вид** (исходный код программы)
- При сдаче необходимо предоставить:
  - ✅ Код программы
  - ✅ Тестовые примеры (включая частные и граничные случаи)
  - ✅ Демонстрацию работы программы

---

### 3. Комплексная работа

После изучения темы **«Функции»** студенты самостоятельно выполняют комплексную работу с использованием ИИ-ассистента.

📄 **Методические указания:** [комплексная_работа.pdf](ссылка)

**Особенности:**
- Работа выполняется с обязательным использованием ИИ
- Необходимо вести журнал промптов
- Требуется критический анализ сгенерированного кода
- Обязательна рефлексия по результатам работы

---

### 4. Контрольные работы

В течение семестра проводятся контрольные работы по основным темам дисциплины для проверки теоретических знаний и практических навыков.

---

## ✅ Требования для получения зачета

Для успешного получения зачета по дисциплине необходимо выполнить **все три условия**:

| № | Требование | Статус |
|---|------------|--------|
| 1 | Защитить **все** индивидуальные задания | Обязательно |
| 2 | Выполнить комплексную работу и получить **не менее 80 баллов** | Обязательно |
| 3 | Получить **«зачтено»** по всем контрольным работам | Обязательно |

---

> ⚠️ **Важно:** Несоблюдение хотя бы одного из требований делает невозможным получение зачета по дисциплине, независимо от успешности выполнения остальных пунктов.
