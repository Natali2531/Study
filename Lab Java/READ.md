# Лабораторные работы по дисциплине "Объектно-ориентированное программирование"

## Общая информация
- **Дисциплина:** Объектно-ориентированное программирование
- **Курс:** 1-й курс
- **Язык программирования:** Java

---

## Модуль 1. Основы ООП

### Лабораторная работа №1. «Первый класс»
**Цель:** Освоение базового синтаксиса Java, создание классов и объектов.

**Задачи:**
- Разработать класс согласно индивидуальному варианту
- Реализовать конструктор по умолчанию и параметризованный конструктор
- Создать методы получения и установки значений полей (геттеры/сеттеры)
- Реализовать метод `toString()` для вывода информации об объекте
- Создать демонстрационную программу с массивом объектов

**Требования:**
- Класс должен содержать минимум 5 полей разных типов
- Обеспечить инкапсуляцию (модификаторы доступа `private`)
- В демонстрационной программе создать не менее 3 объектов

---

### Лабораторная работа №2. «Конструкторы, перегрузка, static»
**Цель:** Изучение перегрузки методов и конструкторов, использования статических членов класса.

**Задачи:**
- Добавить перегруженные конструкторы (минимум 3 варианта)
- Реализовать перегрузку методов (минимум 2 варианта)
- Создать статические поля и методы (счетчик объектов, фабричный метод)
- Использовать ключевое слово `this` для вызова конструкторов
- Реализовать статический блок инициализации

**Требования:**
- Статический счетчик должен автоматически увеличиваться при создании объектов
- Продемонстрировать работу статического метода без создания объекта
- Сравнить перегруженные методы с разными сигнатурами

---

## Модуль 2. Наследование и полиморфизм

### Лабораторная работа №3. «Наследование и полиморфизм»
**Цель:** Освоение механизмов наследования, переопределения методов и полиморфизма.

**Задачи:**
- Создать иерархию классов (базовый класс и минимум 2 производных)
- Использовать ключевое слово `super`
- Переопределить методы базового класса в производных
- Реализовать абстрактный класс и абстрактные методы
- Создать интерфейс и реализовать его в классах
- Продемонстрировать полиморфное поведение (массив базового типа)

**Требования:**
- Иерархия должна иметь глубину минимум 2 уровня
- Использовать ключевые слова `abstract`, `extends`, `implements`
- Показать разницу между переопределением и перегрузкой

## Модуль 3. Коллекции и Generics

### Лабораторная работа №4. «Коллекции»
**Цель:** Изучение фреймворка Java Collections Framework.

**Задачи:**
- Использовать минимум 3 различных коллекции (`ArrayList`, `HashSet`, `HashMap`)
- Реализовать операции добавления, удаления, поиска элементов
- Использовать итераторы для обхода коллекций
- Реализовать сортировку с использованием `Comparator` и `Comparable`
- Преобразование одной коллекции в другую

**Требования:**
- Продемонстрировать работу с коллекциями разных типов
- Реализовать поиск элементов по критериям
- Использовать методы `Collections` для работы с коллекциями

---

### Лабораторная работа №5. «Generics»
**Цель:** Освоение механизма обобщенного программирования.

**Задачи:**
- Создать обобщенный класс с параметром типа
- Реализовать обобщенные методы
- Создать обобщенный интерфейс
- Использовать ограничения (`extends` и `super`) в обобщениях
- Реализовать метод, принимающий коллекцию любого типа

**Требования:**
- Продемонстрировать типобезопасность с Generics
- Использовать wildcards (`?`, `? extends T`, `? super T`)
- Сравнить код с использованием Generics и без

## Модуль 4. Обработка ошибок и форматы данных

### Лабораторная работа №6. «Исключения и логирование»
**Цель:** Изучение механизма обработки исключений и использования логгеров.

**Задачи:**
- Создать иерархию пользовательских исключений (минимум 2 класса)
- Реализовать обработку исключений с использованием `try-catch-finally`
- Использовать `throw` и `throws`
- Настроить логирование с использованием `java.util.logging` или `Log4j`
- Создать собственное непроверяемое и проверяемое исключение

**Требования:**
- Логирование должно быть настроено на разные уровни (INFO, WARNING, SEVERE)
- Исключения должны корректно обрабатываться, программа не должна падать
- В лог должны записываться стектрейсы для исключений

---

### Лабораторная работа №7. «CSV»
**Цель:** Освоение работы с CSV-файлами для хранения и обмена данными.

**Задачи:**
- Реализовать чтение данных из CSV-файла
- Реализовать запись данных в CSV-файл
- Обрабатывать ошибки формата и отсутствия файлов
- Реализовать парсинг CSV с учетом экранирования
- Создать утилитарный класс для работы с CSV

**Требования:**
- Первая строка CSV должна содержать заголовки
- Программа должна корректно обрабатывать пустые значения
- Реализовать преобразование между объектами и CSV-строками

---

### Лабораторная работа №8. «JSON и XML»
**Цель:** Изучение форматов JSON и XML, сериализация/десериализация объектов.

**Задачи:**
- Сериализовать объект в JSON (использовать Jackson или Gson)
- Десериализовать объект из JSON
- Сериализовать объект в XML (использовать JAXB)
- Десериализовать объект из XML
- Обработать аннотации для управления сериализацией

**Требования:**
- Использовать минимум 3 различные библиотеки для работы с JSON и XML
- Продемонстрировать работу с вложенными объектами
- Реализовать преобразование между форматами

## Модуль 5. Многопоточность

### Лабораторная работа №9. «Потоки и синхронизация»
**Цель:** Изучение основ многопоточного программирования, синхронизации потоков.

**Задачи:**
- Создать класс, реализующий интерфейс `Runnable`
- Создать класс, наследующий `Thread`
- Реализовать синхронизацию с использованием `synchronized` методов и блоков
- Использовать методы `wait()`, `notify()`, `notifyAll()`
- Решить проблему гонки данных (race condition)

**Требования:**
- Создать минимум 5 потоков с разными задачами
- Продемонстрировать корректную синхронизацию общего ресурса
- Использовать `volatile` для работы с разделяемыми переменными

---

### Лабораторная работа №10. «ExecutorService и Future»
**Цель:** Изучение Executor Framework для управления пулами потоков.

**Задачи:**
- Создать пул потоков с использованием `ExecutorService`
- Использовать `FixedThreadPool` и `CachedThreadPool`
- Реализовать задачи с возвратом результата (`Callable` и `Future`)
- Использовать `invokeAll()` и `invokeAny()`
- Управлять завершением пула потоков

**Требования:**
- Продемонстрировать работу с `Future.get()` и обработку `TimeoutException`
- Реализовать обработку результатов выполнения задач
- Правильно завершать работу ExecutorService с использованием `shutdown()`

---

## Модуль 6. Работа с базами данных

### Лабораторная работа №11. «JDBC CRUD»
**Цель:** Изучение работы с реляционными базами данных через JDBC.

**Задачи:**
- Подключиться к базе данных (H2, PostgreSQL или MySQL)
- Создать таблицу с помощью JDBC
- Реализовать операции CRUD (Create, Read, Update, Delete)
- Использовать `PreparedStatement` для защиты от SQL-инъекций
- Реализовать получение сгенерированных ключей

**Требования:**
- Использовать отдельный класс-репозиторий для работы с БД
- Реализовать методы для каждой CRUD-операции
- Обрабатывать SQL-исключения
- Закрывать ресурсы (Connection, Statement, ResultSet)

---

### Лабораторная работа №12. «Транзакции и batch»
**Цель:** Изучение транзакционности и пакетной обработки в JDBC.

**Задачи:**
- Реализовать транзакцию с несколькими операциями
- Использовать методы `setAutoCommit(false)`, `commit()`, `rollback()`
- Реализовать пакетную вставку (batch) с использованием `addBatch()`, `executeBatch()`
- Создать точку сохранения (`Savepoint`)
- Обрабатывать ошибки с откатом транзакции

**Требования:**
- Продемонстрировать транзакционность на примере двух связанных таблиц
- Сравнить производительность одиночных и пакетных вставок
- Реализовать обработку частичного выполнения пакета

## Модуль 7. Проектная работа

### Лабораторная работа №13. «ETL: Extract + Transform»
**Цель:** Разработка ETL-процесса для извлечения и преобразования данных.

**Задачи:**
- Реализовать извлечение данных из CSV-файла
- Реализовать извлечение данных из JSON-файла
- Реализовать извлечение данных из XML-файла
- Выполнить трансформацию данных (валидация, очистка, преобразование типов)
- Создать единую модель данных для разных источников

**Требования:**
- Данные должны быть приведены к единому формату
- Реализовать минимум 3 типа трансформаций
- Логировать этапы ETL-процесса

---

### Лабораторная работа №14. «ETL: Load + мониторинг»
**Цель:** Загрузка преобразованных данных и мониторинг ETL-процесса.

**Задачи:**
- Реализовать загрузку данных в базу данных (JDBC)
- Реализовать загрузку данных в CSV-файл
- Реализовать загрузку данных в JSON-файл
- Создать систему мониторинга ETL-процесса (время выполнения, количество записей)
- Реализовать отчет о выполненной работе

**Требования:**
- Поддерживать инкрементальную загрузку (только новые/измененные записи)
- Ведение лога ETL-процесса
- Статистика по каждому этапу ETL

## Рубежный контроль

### Командный мини-проект
**Цель:** Разработка полноценного приложения с использованием всех изученных тем.

**Команда:** 2-3 человека

**Требования к проекту:**
1. **ООП-дизайн:**
   - Иерархия классов (минимум 3 уровня)
   - Использование абстрактных классов и интерфейсов
   - Полиморфизм
2. **Работа с данными:**
   - Чтение/запись в CSV, JSON, XML
   - Использование коллекций (минимум 3 типа)
   - Generics для типобезопасности
3. **База данных:**
   - JDBC CRUD операции
   - Транзакции
   - Пакетная обработка
4. **Многопоточность:**
   - Потоки и синхронизация
   - ExecutorService
5. **Обработка ошибок:**
   - Пользовательские исключения
   - Логирование
6. **Документация:**
   - JavaDoc для всех публичных методов
   - README.md с описанием проекта

**Критерии оценки:**
- Архитектура и дизайн кода (25%)
- Работоспособность (25%)
- Качество кода и стиль (20%)
- Покрытие тестами (15%)
- Документация (15%)

## Примечания к выполнению лабораторных работ

1. Каждая лабораторная работа выполняется в отдельном проекте.
2. Код должен быть оформлен в соответствии с Java Code Conventions.
3. Все классы должны содержать JavaDoc-комментарии.
4. Имена классов, методов и переменных должны быть осмысленными.
5. Для работы с внешними библиотеками использовать Maven или Gradle.
6. При сдаче работы предоставлять:
   - Исходный код
   - Скриншоты выполнения
   - Отчет в формате PDF
