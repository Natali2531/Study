## 2. Теоретические сведения

### 2.1. Установка инструментария разработчика

Для разработки на языке Java необходимо установить два компонента:

**JDK (Java Development Kit)** — комплект разработчика, включающий компилятор, стандартные библиотеки и утилиты. Загружается с официального сайта Oracle (https://www.oracle.com/java/technologies/downloads/) или с сайта Adoptium (https://adoptium.net/). Рекомендуется версия 17 (LTS — Long Term Support).

**IntelliJ IDEA Community Edition** — интегрированная среда разработки (IDE), предоставляющая средства редактирования, компиляции, отладки и запуска программ. Загружается с сайта JetBrains (https://www.jetbrains.com/idea/download/).

После установки необходимо убедиться, что переменная окружения `JAVA_HOME` указывает на каталог установки JDK, а путь к каталогу `bin` добавлен в переменную `PATH`.

### 2.2. Структура программы на языке Java

Вся программа на языке Java состоит из одного или нескольких **классов**. Каждый класс размещается в отдельном файле с расширением `.java`, имя которого совпадает с именем публичного класса.

Минимальная исполняемая программа должна содержать класс с методом `main`, являющимся точкой входа в программу:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

Разбор структуры:
- `public class HelloWorld` — объявление публичного класса с именем `HelloWorld`;
- `public static void main(String[] args)` — сигнатура метода `main`, с которого начинается выполнение программы;
- `System.out.println(...)` — вызов метода вывода строки на консоль с переходом на новую строку.

### 2.3. Типы данных

Язык Java является **строго типизированным**: каждая переменная имеет определённый тип, который указывается при её объявлении и не может быть изменён в процессе выполнения программы.

Типы данных разделяются на две категории:

**Примитивные типы** — хранят непосредственное значение и размещаются в стеке вызовов.

| Тип | Размер | Диапазон значений | Назначение |
|-----|--------|-------------------|------------|
| `byte` | 1 байт | от −128 до 127 | Целые числа малого диапазона |
| `short` | 2 байта | от −32 768 до 32 767 | Целые числа |
| `int` | 4 байта | от −2 31 до 2 31 − 1 | Целые числа (основной тип) |
| `long` | 8 байт | от −2 63 до 2 63 − 1 | Целые числа большого диапазона |
| `float` | 4 байта | ≈ ±3.4 × 10³⁸ | Вещественные числа одинарной точности |
| `double` | 8 байт | ≈ ±1.7 × 10³⁰⁸ | Вещественные числа двойной точности |
| `char` | 2 байта | символы Unicode | Одиночные символы |
| `boolean` | — | `true` или `false` | Логические значения |

**Ссылочные типы** — хранят ссылку на объект в динамической памяти (куче). К ссылочным типам относятся классы, массивы, строки (`String`) и интерфейсы.

```java
int age = 20;                  // примитивный тип
double grade = 4.75;           // примитивный тип
boolean isStudent = true;      // примитивный тип
char initial = 'А';            // примитивный тип
String name = "Иван";          // ссылочный тип (объект класса String)
```

### 2.4. Переменные и константы

**Переменная** — именованная область памяти, предназначенная для хранения значения определённого типа. Объявление переменной состоит из указания типа и имени:

```java
int count;          // объявление переменной
count = 10;         // присваивание значения
int quantity = 5;   // объявление с инициализацией
```

**Константа** — переменная, значение которой не может быть изменено после инициализации. Объявляется с использованием модификатора `final`:

```java
final double PI = 3.14159265;
final int MAX_STUDENTS = 30;
```

Имена констант принято записывать прописными буквами с разделением слов символом подчёркивания.

### 2.5. Операторы

Язык Java поддерживает следующие категории операторов:

**Арифметические операторы:** `+`, `-`, `*`, `/`, `%` (остаток от деления), `++` (инкремент), `--` (декремент).

**Операторы сравнения:** `==`, `!=`, `>`, `<`, `>=`, `<=`.

**Логические операторы:** `&&` (логическое И), `||` (логическое ИЛИ), `!` (логическое НЕ).

**Операторы присваивания:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`.

```java
int a = 10;
int b = 3;
int sum = a + b;           // 13
int remainder = a % b;     // 1
boolean condition = (a > b) && (b != 0);  // true
a += 5;                    // эквивалентно a = a + 5;
```

### 2.6. Управляющие конструкции

**Условный оператор `if`:**

```java
if (условие) {
    // блок кода, выполняемый при истинности условия
} else if (другое_условие) {
    // блок кода, выполняемый при истинности другого условия
} else {
    // блок кода, выполняемый при ложности всех условий
}
```

**Оператор множественного выбора `switch`:**

```java
switch (выражение) {
    case значение1:
        // действия
        break;
    case значение2:
        // действия
        break;
    default:
        // действия по умолчанию
}
```

**Цикл `for`:**

```java
for (инициализация; условие; итерация) {
    // тело цикла
}

// Пример:
for (int i = 0; i < 10; i++) {
    System.out.println("Итерация: " + i);
}
```

**Цикл `while`:**

```java
while (условие) {
    // тело цикла
}
```

**Цикл `do-while`** (с постусловием):

```java
do {
    // тело цикла
} while (условие);
```

### 2.7. Массивы

**Массив** — упорядоченная коллекция элементов одного типа, размещаемая в динамической памяти. Размер массива фиксируется при создании и не может быть изменён.

```java
// Объявление и создание массива
int[] numbers = new int[5];           // массив из 5 целых чисел
numbers[0] = 10;                      // обращение по индексу (от 0)
numbers[1] = 20;

// Объявление с инициализацией
int[] values = {1, 2, 3, 4, 5};

// Получение длины массива
int length = values.length;           // 5

// Обход массива
for (int i = 0; i < values.length; i++) {
    System.out.println(values[i]);
}

// Улучшенный цикл for (for-each)
for (int value : values) {
    System.out.println(value);
}
```

### 2.8. Методы

**Метод** — именованная группа инструкций, выполняющая определённое действие. Методы позволяют структурировать код и обеспечивать его повторное использование.

Синтаксис объявления метода:

```java
модификаторы тип_возврата имя_метода(параметры) {
    // тело метода
    return значение;  // если тип_возврата не void
}
```

Примеры:

```java
// Метод без параметров и без возвращаемого значения
public static void printGreeting() {
    System.out.println("Здравствуйте!");
}

// Метод с параметрами и возвращаемым значением
public static int sum(int a, int b) {
    return a + b;
}

// Метод с несколькими параметрами
public static double calculateAverage(double first, double second, double third) {
    return (first + second + third) / 3.0;
}
```

Вызов методов:

```java
printGreeting();
int result = sum(5, 7);
double avg = calculateAverage(4.0, 5.0, 3.0);
```

В рамках настоящей работы методы объявляются со статическим модификатором `static`, поскольку выполняются в контексте метода `main`. Понятие нестатических методов будет раскрыто при изучении классов и объектов.

### 2.9. Первый класс и объект

**Класс** — это тип данных, определяющий структуру (набор полей) и поведение (набор методов) группы однородных объектов. В самом простом виде класс может содержать только поля — переменные, описывающие состояние объекта.

**Объект (экземпляр класса)** — конкретная сущность, созданная по шаблону, заданному классом. Создание объекта выполняется оператором `new`.

```java
// Объявление класса
public class Student {
    String name;          // поле класса
    int age;              // поле класса
    String group;         // поле класса
}

// Создание и использование объекта
public class Main {
    public static void main(String[] args) {
        Student student = new Student();   // создание объекта
        student.name = "Иванов Иван";      // установка значения поля
        student.age = 19;
        student.group = "ПИ-21";

        System.out.println("Имя: " + student.name);
        System.out.println("Возраст: " + student.age);
        System.out.println("Группа: " + student.group);
    }
}
```

Обращение к полям объекта осуществляется посредством оператора `.` (точка). В дальнейшем поля классов будут объявляться с модификатором `private`, а доступ к ним будет осуществляться через методы-аксессоры (геттеры и сеттеры).

### 2.10. Ввод и вывод данных

**Вывод данных** осуществляется посредством обращения к объекту `System.out`:

```java
System.out.println("Строка с переходом на новую строку");
System.out.print("Строка без перехода на новую строку");
System.out.printf("Форматированный вывод: %d, %.2f\n", 42, 3.14159);
```

**Ввод данных** с консоли осуществляется посредством класса `Scanner`:

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Введите имя: ");
        String name = scanner.nextLine();

        System.out.print("Введите возраст: ");
        int age = scanner.nextInt();

        System.out.println("Имя: " + name + ", возраст: " + age);

        scanner.close();  // закрытие ресурса
    }
}
```

## 3. Примеры выполнения

### 3.1. Пример 1. Простая программа с вводом и выводом данных

```java
import java.util.Scanner;

/**
 * Программа вычисляет площадь прямоугольника по введённым сторонам.
 * Демонстрирует использование Scanner, арифметических операций
 * и форматированного вывода.
 */
public class RectangleArea {
    public static void main(String[] args) {
        // Создание объекта Scanner для чтения данных с консоли
        Scanner scanner = new Scanner(System.in);

        scanner.close();
    }
```

### 3.2. Пример 2. Использование массивов и методов

```java
import java.util.Scanner;

/**
 * Программа вычисляет статистические характеристики массива оценок:
 * среднее значение, минимальную и максимальную оценки.
 * Демонстрирует использование массивов, циклов и методов.
 */
public class GradeStatistics {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Ввод количества оценок
        System.out.print("Введите количество оценок: ");
        int count = scanner.nextInt();

        // Создание массива и ввод оценок
        double[] grades = new double[count];
        for (int i = 0; i < count; i++) {
            System.out.printf("Введите оценку #%d: ", i + 1);
            grades[i] = scanner.nextDouble();
        }

        // Вывод результатов
        System.out.printf("Средняя оценка: %.2f%n", calculateAverage(grades));
        System.out.println("Минимальная оценка: " + findMin(grades));
        System.out.println("Максимальная оценка: " + findMax(grades));

        scanner.close();
    }

    /**
     * Вычисляет среднее арифметическое элементов массива.
     *
     * @param grades массив оценок
     * @return среднее значение
     */
    public static double calculateAverage(double[] grades) {
        double sum = 0;
        for (double grade : grades) {
            sum += grade;
        }
        return sum / grades.length;
    }

    /**
     * Находит минимальный элемент массива.
     *
     * @param grades массив оценок
     * @return минимальное значение
     */
    public static double findMin(double[] grades) {
        double min = grades[0];
        for (double grade : grades) {
            if (grade < min) {
                min = grade;
            }
        }
        return min;
    }

    /**
     * Находит максимальный элемент массива.
     *
     * @param grades массив оценок
     * @return максимальное значение
     */
    public static double findMax(double[] grades) {
        double max = grades[0];
        for (double grade : grades) {
            if (grade > max) {
                max = grade;
            }
        }
        return max;
    }
}
```

## 6. Методические указания к самостоятельной работе

1. **Создание проекта.** Создайте в интегрированной среде разработки новый проект типа «Java Project». В рамках проекта создайте пакет (например, `com.university.lab1`), в котором разместите все файлы классов.

2. **Структура файлов.** Каждый класс размещается в отдельном файле, имя которого совпадает с именем класса. Демонстрационный класс с методом `main` рекомендуется именовать с суффиксом `Demo` (например, `StudentDemo.java`).

3. **Именование.** При именовании классов используйте `CamelCase` (каждое слово с прописной буквы). При именовании переменных и методов используйте `camelCase` (первое слово со строчной буквы, последующие — с прописной).

4. **Комментарии.** Каждый класс должен сопровождаться Javadoc-комментарием, описывающим его назначение. Методы также должны сопровождаться комментариями с указанием назначения и параметров.

5. **Инициализация объектов.** Поля объектов могут инициализироваться как непосредственно в коде метода `main`, так и посредством вызова методов-мутаторов (если таковые реализованы).

6. **Дополнительные операции.** В демонстрационном классе необходимо реализовать не менее двух статических методов, выполняющих операции с массивами объектов (вычисления, сравнения, поиск).

7. **Тестирование.** Перед сдачей работы убедитесь, что программа корректно компилируется и выполняет все заявленные операции. Проверьте корректность вывода данных.

8. **Оформление отчёта.** В отчёт включите листинги всех файлов проекта, протокол работы программы и ответы на контрольные вопросы.
