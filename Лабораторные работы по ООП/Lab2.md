## 2. Теоретический конспект

### 2.1. Конструкторы

**Конструктор** — специальный метод, вызываемый при создании объекта для инициализации его состояния.

**Особенности:**
- имя совпадает с именем класса;
- не имеет возвращаемого типа;
- если не определён ни один конструктор, компилятор создаёт конструктор по умолчанию.

```java
public class Book {
    private long id;
    private String title;
    private String author;
    private int year;

    // Конструктор по умолчанию
    public Book() {
        this(0, "Без названия", "Неизвестен", 0);
    }

    // Конструктор с параметрами
    public Book(long id, String title, String author, int year) {
        this.id = id;
        setTitle(title);
        setAuthor(author);
        setYear(year);
    }
}
```

### 2.2. Перегрузка конструкторов

**Перегрузка** — наличие в классе нескольких методов (или конструкторов) с одинаковым именем, но различными списками параметров.

```java
public Book(String title, String author) {
    this(0, title, author, 0);  // вызов основного конструктора
}

public Book(String title, String author, int year) {
    this(0, title, author, year);
}
```

**Правило:** вызов одного конструктора из другого через `this(...)` должен быть **первой инструкцией** в теле конструктора.

### 2.3. Статические члены класса

**Статическое поле** принадлежит не объекту, а классу в целом. Существует в единственном экземпляре.

**Статический метод** может обращаться только к статическим членам.

```java
public class Book {
    private static int counter = 0;  // счётчик созданных объектов
    private long id;

    public Book(String title, String author, int year) {
        this.id = ++counter;  // автоинкремент ID
        setTitle(title);
        setAuthor(author);
        setYear(year);
    }

    public static int getCounter() {
        return counter;
    }
}
```

### 2.4. Фабричные методы

**Фабричный метод** — статический метод, создающий и возвращающий новый объект. Преимущества перед конструктором:
- может иметь осмысленное имя;
- может возвращать подкласс;
- может кэшировать объекты.

```java
public static Book createBook(String title, String author, int year) {
    return new Book(title, author, year);
}

// Использование
Book book = Book.createBook("Война и мир", "Толстой Л.Н.", 1869);
```

### 2.5. Перегрузка методов

```java
public String getDescription() {
    return "\"" + title + "\" — " + author + " (" + year + ")";
}

public String getDescription(boolean shortFormat) {
    if (shortFormat) {
        return title + " (" + year + ")";
    }
    return getDescription();
}
```

## 5. Методические указания

1. **Вызов `this(...)`** должен быть первой инструкцией в конструкторе.
2. **Статический счётчик** увеличивается в основном конструкторе, чтобы учитывать все способы создания объекта.
3. **Фабричный метод** — это альтернатива конструктору, а не его замена.
4. **Перегруженные методы** должны иметь различающиеся списки параметров (по количеству или типам).
