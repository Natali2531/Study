## 2. Теоретический конспект

### 2.1. Иерархия коллекций

```
Collection
├── List (упорядоченная коллекция)
│   ├── ArrayList — быстрый доступ по индексу
│   └── LinkedList — быстрая вставка/удаление
├── Set (уникальные элементы)
│   ├── HashSet — по хеш-коду
│   └── TreeSet — по сравнению
└── Queue (очередь)

Map (ключ-значение)
├── HashMap — по хеш-коду
└── TreeMap — по сравнению ключей
```

### 2.2. Основные операции

```java
// List
List<Book> books = new ArrayList<>();
books.add(book1);
books.sort(Comparator.comparing(Book::getYear));

// Set
Set<Book> uniqueBooks = new HashSet<>();
uniqueBooks.add(book1);  // дубликаты не добавляются

// Map
Map<String, List<Book>> booksByAuthor = new HashMap<>();
booksByAuthor.computeIfAbsent(author, k -> new ArrayList<>()).add(book);
```

### 2.3. Переопределение equals() и hashCode()

Для корректной работы Set необходимо переопределить equals() и hashCode():

```java
@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (o == null || getClass() != o.getClass()) return false;
    Book book = (Book) o;
    return year == book.year &&
           Objects.equals(title, book.title) &&
           Objects.equals(author, book.author);
}

@Override
public int hashCode() {
    return Objects.hash(title, author, year);
}
```

### 2.4. Stream API

```java
List<Book> filtered = books.stream()
    .filter(b -> b.getYear() > 2000)
    .sorted(Comparator.comparing(Book::getTitle))
    .collect(Collectors.toList());

Map<String, Long> countByAuthor = books.stream()
    .collect(Collectors.groupingBy(Book::getAuthor, Collectors.counting()));
```

## 5. Методические указания

1. **Переопределение equals() и hashCode()** обязательно для корректной работы Set.
2. **Stream API** применяется для фильтрации и агрегации без явных циклов.
3. **Замер производительности** выполняется с использованием `System.currentTimeMillis()` или `System.nanoTime()`.
4. **Используйте ИИ-инструмент** для генерации equals()/hashCode(), но обязательно проверьте результат.
5. **Ведите журнал применения ИИ** — это обязательная часть отчёта.
