# Модуль 1. Введение в объектно-ориентированное программирование на языке Java

## 1. Паспорт модуля

| Параметр | Значение |
|----------|----------|
| Дисциплина | Объектно-ориентированное программирование |
| Курс / семестр | 2 курс / 3 семестр |
| Количество занятий | 4 лабораторные работы |
| Трудоемкость | 16 академических часов аудиторной работы + самостоятельная работа |
| Язык программирования | Java (JDK 17 и выше) |

## 2. Место модуля в структуре дисциплины

Модуль 1 является вводным модулем дисциплины «Объектно-ориентированное программирование» и предназначен для обучающихся, **не имеющих предварительного опыта разработки на языке Java**. В ходе освоения модуля осуществляется последовательный переход от базовых синтаксических конструкций языка к фундаментальным принципам объектно-ориентированного программирования.

Модуль закладывает основу для последующего изучения продвинутых механизмов языка (обобщения, коллекции, многопоточность), архитектурных принципов (SOLID) и интеграции с современными инструментами разработки, включая средства искусственного интеллекта.

## 3. Входные требования

От обучающихся **не требуется** предварительное знание языка Java. Для успешного освоения модуля достаточно следующих компетенций, сформированных в предшествующих дисциплинах:

- базовые знания алгоритмизации (линейные, разветвляющиеся, циклические алгоритмы);
- общее представление о переменных, типах данных и управляющих конструкциях на примере любого языка программирования;
- умение работать в операционной системе (файловые операции, запуск приложений);
- элементарные навыки работы в текстовом редакторе.

В первой лабораторной работе модуля проводится вводный инструктаж по установке и настройке инструментария разработчика, а также изучение базового синтаксиса языка Java в объёме, достаточном для выполнения последующих заданий.

## 4. Цели и задачи модуля

### 4.1. Цель модуля

Формирование у обучающихся базовых навыков разработки на языке Java и освоение фундаментальных принципов объектно-ориентированного программирования: инкапсуляции, наследования, полиморфизма и абстракции.

### 4.2. Задачи модуля

По результатам освоения модуля обучающийся должен:

**Знать:**
- базовый синтаксис языка Java: типы данных, переменные, операторы, управляющие конструкции, массивы;
- структуру программы на Java и механизм её компиляции и выполнения;
- основные принципы объектно-ориентированного программирования (инкапсуляция, наследование, полиморфизм, абстракция);
- механизмы контроля доступа в языке Java;
- различия между абстрактными классами и интерфейсами;
- области применения наследования и композиции.

**Уметь:**
- создавать, компилировать и выполнять программы на языке Java;
- проектировать классы на основе анализа предметной области;
- применять инкапсуляцию для защиты инвариантов объектов;
- строить иерархии классов с использованием наследования;
- реализовывать полиморфное поведение через переопределение методов;
- определять контракты взаимодействия между классами посредством интерфейсов.

**Владеть:**
- методикой декомпозиции предметной области на классы и объекты;
- инструментарием интегрированной среды разработки для создания и отладки программ;
- базовыми приёмами рефакторинга процедурного кода в объектно-ориентированный стиль.

## 6. Организация учебного процесса

### 6.1. Формат выполнения работ

Каждая лабораторная работа состоит из двух частей:

1. **Задание, выполняемое в аудитории** — отрабатывается под руководством преподавателя, служит основой для закрепления теоретического материала.
2. **Задание для самостоятельной работы** — выполняется обучающимся вне аудитории в соответствии с индивидуальным вариантом (предусмотрено 30 вариантов) и защищается на следующем занятии.

### 6.2. Требования к программному коду

К программному коду, представляемому на защиту, предъявляются следующие требования:

- соответствие соглашениям Java Code Conventions;
- осмысленное именование классов, методов и переменных;
- наличие комментариев, поясняющих ключевые участки кода;
- отсутствие предупреждений интегрированной среды разработки;
- наличие валидации входных данных в методах-мутаторах;
- разделение кода на отдельные файлы в соответствии с принципом «один публичный класс — один файл».

### 6.3. Требования к отчету по лабораторной работе

Отчет по каждой лабораторной работе должен содержать:

1. Титульный лист установленного образца.
2. Цель и задачи работы.
3. Листинги программного кода с пояснительными комментариями.
4. Результаты выполнения программы (протокол работы в консоли).
5. Ответы на контрольные вопросы.
6. Выводы по проделанной работе.

### 6.4. Подготовка к первому занятию

Перед первой лабораторной работой обучающимся рекомендуется:

- установить JDK версии 17 или выше;
- установить интегрированную среду разработки (IntelliJ IDEA Community Edition);
- ознакомиться с интерфейсом среды разработки посредством выполнения демонстрационного проекта.

Подробные инструкции по установке и настройке приведены в лабораторной работе №1.

## 7. Политика использования средств искусственного интеллекта

В рамках модуля допускается применение инструментов искусственного интеллекта (Copilot, ChatGPT, Qwen и аналогов) при соблюдении следующих ограничений:

**Допускается:**
- получение пояснений по синтаксическим конструкциям языка Java;
- генерация шаблонного кода (boilerplate);
- написание модульных тестов;
- поиск синтаксических и логических ошибок;
- объяснение сообщений компилятора и среды выполнения.

**Не допускается:**
- делегирование ИИ проектирования архитектуры решения;
- использование сгенерированного кода без понимания его семантики;
- копирование решений без последующего анализа и модификации.

Обучающийся обязан пояснить каждое решение, присутствующее в сдаваемой работе, и обосновать принятые проектные решения. На защите лабораторной работы преподаватель вправе задать вопросы по любому фрагменту кода.
